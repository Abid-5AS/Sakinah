## User Personas

### Persona 1: Thoughtful Tahmid
**Demographics:**
- Age: 24
- Location: Dhaka, Bangladesh
- Occupation: Electrical Engineering student at BUET
- Education: Undergraduate
- Tech Proficiency: High

**Background:**
Tahmid grew up in a practicing Muslim family. He prays five times a day and fasts during Ramadan, but lately feels his religious practice has become mechanical. He wants to develop a deeper, more conscious connection with his faith. He's concerned about digital privacy and doesn't trust apps that require constant internet connection.

**Goals:**
- Understand the deeper meanings of Islamic teachings
- Connect daily experiences with spiritual growth
- Memorize the 99 Names of Allah
- Develop a habit of spiritual reflection
- Maintain privacy of personal thoughts

**Pain Points:**
- Feels disconnected during prayer despite regular practice
- Struggles to remember what he learns from Friday khutbahs
- Wants to journal but fears lack of privacy
- Finds most Islamic apps too simplistic or untrustworthy
- Limited time between classes and study

**Device Usage:**
- Android phone (Samsung Galaxy)
- Uses phone 4-5 hours daily
- Primarily in Bengali and English
- Often in areas with poor internet connection (university campus)

---

### Persona 2: Reflective Raisa
**Demographics:**
- Age: 31
- Location: Chittagong, Bangladesh
- Occupation: Senior Software Engineer
- Education: Master's in Computer Science
- Tech Proficiency: Very High

**Background:**
Raisa has been keeping a personal journal since her teenage years. She's a practicing Muslim who tries to incorporate Islamic values into her work life. As a tech professional, she's very aware of data privacy issues and app security. She wants to combine her journaling habit with spiritual growth.

**Goals:**
- Integrate spiritual reflection into daily journaling
- Learn authentic Islamic knowledge with proper sources
- Find moments of peace during her busy work schedule
- Teach her younger sister about Islamic spirituality
- Keep personal reflections completely private

**Pain Points:**
- Busy schedule limits time for deep Islamic study
- Distrusts apps that collect personal data
- Wants to verify authenticity of Islamic content
- Needs Bengali content for family members
- Frustrated by apps with unclear sources

**Device Usage:**
- iPhone 14 Pro
- iPad for reading
- Values clean, minimalist design
- Uses dark mode exclusively
- Works offline frequently while traveling

## User Journey Maps

### Journey 1: Tahmid's First Week

#### Day 1: Discovery and Setup
1. Downloads Sakinah after a friend's recommendation
2. Opens app, reads the welcome message in Bengali
3. Sets up biometric lock (fingerprint)
4. Reads brief tutorial about the four pillars
5. Explores the Library - impressed by Hadith authenticity grades
6. Writes first journal entry about feeling spiritually disconnected

#### Day 3: First Reflection Suggestion
1. Writes about stress over upcoming exams
2. Companion suggests "Al-Fattah" (The Opener)
3. Taps on suggestion, reads full explanation in Library
4. Verifies the suggested Hadith - sees it's from Sahih Bukhari
5. Feels comforted, bookmarks the Name
6. Starts flashcard practice with 5 Names

#### Day 7: Building the Habit
1. App becomes part of evening routine
2. Writes shorter entries but more consistently
3. Reviews flashcards during commute (offline)
4. Notices he's starting to think about Names during the day
5. Shares app with roommate
6. Sets personal goal to memorize 10 Names this month

## Feature-Based User Stories

### Pillar 1: The Sanctuary (Journal)

#### Setup and Security
```
As a privacy-conscious user,
I want to lock my journal with biometric authentication,
So that my personal reflections remain completely private.
```

```
As a new user,
I want to understand what happens to my data,
So that I can trust the app with my personal thoughts.
```

```
As a user concerned about data loss,
I want to backup my journal locally,
So that I don't lose my reflections if I change devices.
```

#### Journal Entry Creation
```
As a regular journaler,
I want a distraction-free writing interface,
So that I can focus on my spiritual reflection.
```

```
As a bilingual user,
I want to write in both Bengali and English,
So that I can express myself in whichever language feels natural.
```

```
As a busy professional,
I want to add quick voice notes (future feature),
So that I can capture reflections when I can't type.
```

```
As a reflective person,
I want to tag my entries with emotions or themes,
So that I can see patterns in my spiritual journey.
```

#### Journal Review and Reflection
```
As a user tracking spiritual growth,
I want to review my past entries,
So that I can see how my understanding has evolved.
```

```
As someone seeking patterns,
I want to see which Names appear most in my entries,
So that I understand which attributes I'm most drawn to.
```

```
As a visual person,
I want to see a timeline of my spiritual journey,
So that I can visualize my progress.
```

---

### Pillar 2: The Library (Knowledge Vault)

#### Quran Features
```
As a Quran reader,
I want to access the full Quran with Bengali translation,
So that I can understand the meaning in my native language.
```

```
As a student of Quran,
I want to bookmark specific verses,
So that I can quickly return to meaningful passages.
```

```
As someone seeking understanding,
I want to read tafsir for verses,
So that I can understand the context and deeper meanings.
```

```
As a researcher,
I want to search for verses by theme or keyword,
So that I can find relevant guidance for specific situations.
```

#### Hadith Features
```
As a seeker of authentic knowledge,
I want to see the authenticity grade of each Hadith,
So that I know which narrations are reliable.
```

```
As a careful Muslim,
I want to see the complete chain of narration,
So that I can verify the source myself.
```

```
As a learner,
I want to search Hadith by topic,
So that I can find guidance on specific issues.
```

```
As a teacher,
I want to share specific Hadith with proper attribution,
So that I can teach others with accuracy.
```

#### 99 Names Features
```
As a memorizer,
I want to see each Name with Arabic, transliteration, and meaning,
So that I can learn pronunciation and understanding together.
```

```
As a deep learner,
I want to understand the etymology and root of each Name,
So that I can appreciate the linguistic beauty.
```

```
As a spiritual seeker,
I want to see how Names relate to each other,
So that I understand the interconnected attributes of Allah.
```

```
As a practical Muslim,
I want to see real-life examples of each Name,
So that I can recognize them in my daily life.
```

### Pillar 3: The Companion (Reflective Engine)

#### Intelligent Suggestions
```
As a journal writer,
I want relevant Names suggested based on my entry,
So that I can deepen my reflection.
```

```
As a Quran student,
I want related verses suggested for my journal entry,
So that I can connect my experience to divine guidance.
```

```
As someone seeking wisdom,
I want relevant Hadith suggested for my situation,
So that I can learn from the Prophet's teachings.
```

```
As a privacy-conscious user,
I want confirmation that analysis happens on my device,
So that I know my journal never leaves my phone.
```

#### Reflection Patterns
```
As a growing Muslim,
I want to see weekly summaries of my spiritual themes,
So that I can understand my spiritual state.
```

```
As someone seeking improvement,
I want to identify Names I haven't reflected on recently,
So that I can broaden my understanding of Allah's attributes.
```

```
As a self-aware person,
I want to see which emotions are most common in my entries,
So that I can work on my emotional spiritual health.
```

#### Daily Engagement
```
As a consistent user,
I want gentle daily prompts for reflection,
So that I maintain my journaling habit.
```

```
As someone seeking variety,
I want different types of reflection prompts,
So that my practice doesn't become mechanical.
```

```
As a mindful Muslim,
I want reminders based on my routine (not time-based spam),
So that the app respects my schedule.
```

### Pillar 4: The Guide (Learning Path)

#### Memorization System
```
As a memorizer,
I want a spaced repetition system for the 99 Names,
So that I retain what I learn long-term.
```

```
As a beginner,
I want to start with a few Names and gradually increase,
So that I don't feel overwhelmed.
```

```
As a visual learner,
I want flashcards with beautiful typography,
So that learning is aesthetically pleasing.
```

```
As someone tracking progress,
I want to see how many Names I've mastered,
So that I stay motivated.
```

#### Learning Tools
```
As a pronunciation learner,
I want to hear correct Arabic pronunciation (future feature),
So that I can recite Names properly.
```

```
As a connection seeker,
I want a visual map showing related Names,
So that I understand thematic groupings.
```

```
As a customizable learner,
I want to set my own learning pace,
So that I can balance this with other commitments.
```

#### Graduation Progress
```
As a long-term user,
I want to see my journey toward "graduation",
So that I understand when I've internalized the practice.
```

```
As someone seeking independence,
I want the app to celebrate when I'm ready to graduate,
So that I know I've achieved the goal.
```

```
As a graduated user,
I want to keep the Library accessible even after graduation,
So that I can still reference authentic sources.
```

## Edge Cases and Special Scenarios

### Accessibility Scenarios
```
As a visually impaired user,
I want full screen reader support,
So that I can use all features of the app.
```

```
As a user with motor difficulties,
I want large touch targets and voice input,
So that I can journal comfortably.
```

```
As an elderly user,
I want adjustable font sizes,
So that I can read without strain.
```

### Technical Edge Cases
```
As a user with limited storage,
I want to select which Hadith collections to download,
So that I can manage my device space.
```

```
As someone changing devices,
I want to export my journal in encrypted format,
So that I can migrate without losing data.
```

```
As a user who lost their device,
I want my journal to be unrecoverable by others,
So that my privacy is protected even if device is stolen.
```

### Cultural and Religious Scenarios
```
As a convert to Islam,
I want explanations of Islamic terminology,
So that I can understand concepts new to me.
```

```
As a parent,
I want to share appropriate content with my children,
So that they can learn in an age-appropriate way.
```

```
As a scholar reviewing the app,
I want to verify all sources and attributions,
So that I can endorse it for my community.
```

```
As someone in a non-Muslim country,
I want the app to work completely offline,
So that I can maintain my practice anywhere.
```

### Special Bangladeshi Context
```
As a Bangladeshi Muslim during Ramadan,
I want special Ramadan-themed reflections and content,
So that the app aligns with the blessed month.
```

```
As someone with limited mobile data,
I want all features to work offline,
So that I don't incur data charges.
```

```
As a madrasa student,
I want to reference classical scholarly opinions,
So that my learning aligns with traditional Islamic education.
```

```
As a Bangladeshi woman,
I want privacy features that protect me in shared family devices,
So that I can journal without family members accessing my private thoughts.
```

## User Story Prioritization

### Must Have (MVP - Phase 1)
- Journal creation and encryption
- Biometric lock
- 99 Names library with basic information
- Basic Quran with Bengali translation
- Simple flashcard system for Names
- Basic Companion suggestions

### Should Have (Phase 2)
- Full Hadith collections with grading
- Advanced search in Library
- Spaced repetition system
- Visual connection maps
- Weekly reflection summaries
- Multiple translation options

### Could Have (Phase 3)
- Voice notes
- Audio pronunciation
- Tafsir integration
- Family sharing (privacy-preserved)
- Export/import functionality
- Advanced analytics

### Won't Have (Out of Scope)
- Social features (contradicts privacy goal)
- Cloud sync (contradicts offline-first)
- Gamification with leaderboards
- Push notifications for engagement
- Advertisement integration
